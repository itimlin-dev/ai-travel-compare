# AI 旅遊選團通 V1.2 測試版

## 更新
- 模式二：每團新增「從網址取得行程資料」及「貼上行程文字」按鈕。
- 匯入結果先預覽，預設只填空白欄位；六大評分不會自動填寫。

## 部署注意（重要）
網址自動讀取功能使用 `functions/api/extract.js`，屬於 **Cloudflare Pages Functions**。請以支援 Pages Functions 的 Git 整合或 Wrangler 部署方式發佈整個專案；僅雙擊 `index.html` 或以純靜態檔案／Workers 靜態資產部署時，網址讀取 API 不會生效，但「貼上行程文字」仍可使用。

如使用 Cloudflare Pages 的直接拖放上傳 ZIP，請先確認部署流程是否支援 functions 資料夾；若不支援，請改採 Git/Wrangler 部署。

## 限制
旅行社網站可能使用 JavaScript 動態載入、反機器人保護或重新導向；網頁文字解析屬啟發式整理，團費／天數／欄位可能誤判，匯入前請核對。網頁若為 PDF，請手動複製文字。網址擷取會由伺服器連線到來源網站，不保證所有網站可讀。

資料仍存放在目前網站來源的瀏覽器 localStorage；若更換網域，資料不會自動搬移。
